# Curso HTML e CSS

Trilha didática para estudantes iniciantes em desenvolvimento web.

## Objetivo

Aprender a estruturar páginas web com HTML, aplicar estilos com CSS e desenvolver boas práticas de organização, semântica e acessibilidade.

## Público-alvo

Estudantes iniciando em programação web.

## Conteúdos previstos

- Estrutura básica de uma página HTML
- Textos, links, imagens e listas
- Tabelas e formulários
- HTML semântico
- Introdução ao CSS
- Seletores, cores, espaçamentos e layout
- Boas práticas de organização
- Exercícios e projeto final
